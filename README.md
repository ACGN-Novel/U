## 说明

- 首拼规则：取书名第一个汉字拼音首字母（多音字按词组上下文注音，如「重生」归 C）；
  英文书名取首字母；书名前数字序号不计入首拼，书名号《》保留。
- 每个仓库内有按站点分类的目录与完整书目列表，见各仓库 README。
- 每周由 GitHub Actions 自动与源站同步一次。
